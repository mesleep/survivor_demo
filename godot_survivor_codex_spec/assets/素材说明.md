# 四宠庭院素材库

本轮图像使用内置 imagegen 生成/编辑，未使用外部素材库或第三方角色。参考照片由用户提供，仅取宠物外观，不把原始照片或照片中人物收入仓库。生成物不附带第三方开源授权声明。

## 素材及用法

- `sprites/pets/虎妞与黑豹.png`：1774×887，四列两行；当前仅第二行用于黑豹，保留原始版本。
- `sprites/pets/虎妞绷脸版.png`：同尺寸，当前仅第一行用于虎妞；半眯小眼、闭嘴绷脸。黑豹继续引用原图，完全不受修订影响。
- `sprites/pets/小四与小七.png`：1774×887，四列两行；第一行小四，第二行小七。小七依照片保留深色虎斑，而不是纯黑色。
- `sprites/pets/庭院武器.png`：1448×1086，四列三行；飞叶刃、回旋骨棒、环绕铃铛各四帧，用于持有表现及弹体动画。
- `backgrounds/月光庭院.png`：完整俯视庭院背景，装饰不增加物理障碍；原有边界保持不变。
- `audio/`：月光散步（19.2 秒循环）、星光发射、宝石拾取、轻巧击退、升级铃声、领主出现、守护成功、休息时刻。由 `tools/generate_audio.py` 原创合成，22050 Hz 单声道 16-bit PCM，可重复生成，无外部依赖。

PNG 保留透明通道，SpriteFrames 由 AtlasTexture 裁切，使用最近邻过滤；所有战斗数值在 `data/` 中，不写入图片。
