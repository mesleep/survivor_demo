## 一致性检查表

- 十候选是**可获得池**，不是开局携带十件；六格是**同时持有上限**，不可混淆。
- “子弹数量 +1”“射击轮次 +1”“穿透敌人数 +1”是三个独立属性、独立测试。
- 一件装备的“基础等级”“质变分支”“分支专属等级”是不同运行时状态；刷新选项不改变任何一个状态。
- 角色通用 Buff、单件装备 Buff、永久成长分别有归属；重开仅清局内状态。
- 金币同局掉落与结算金币的来源独立，结算不能因重开/重复信号重复入账。
- 设计稿中的既有影视/动漫/游戏只作为玩法意象，不复制受保护造型、名称或标识。
- **所有玩法数值必须可配置**（2026-09-25 用户要求）：伤害、冷却、概率、上限、价格、经验曲线、生成参数、结算公式等一律放在 `Resource` 或 `@export` 字段中，禁止写死在脚本里；确需常量时必须在代码注释与规则决策中说明理由。已实现的数值若仍写死，应在触及相关任务时迁出。
