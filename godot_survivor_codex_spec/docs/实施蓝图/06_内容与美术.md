# 06｜后续内容、美术债和最终验收

这组任务并非默认“再加一堆内容”。原设计中的剑、敌人、地图、装扮多处尚未写规则。先生成明确设计卡再编码/制图；没有定稿时标记待确认，不虚报完成。所有素材遵守[美术素材清单](../整理设计/美术素材清单.md)的暗色漫画风、透明 PNG、视角、帧基线和原创要求。

## T32 基础剑与近战扇形

- 输入：`WeaponDefinition`、`TargetingService`、T10 伤害管线；先定目标方位、扇形角/半径、一次挥砍每敌命中次数、冷却与基础等级。剑的质变在源稿中为空，**不属于此任务**。
- 操作：用可复用近战攻击形态/命中区域，不把“无限速短寿命子弹”当作未说明的替代方案；对准最近合法目标一侧，空目标不挥砍。加入武器候选、获取和基础升级。交付 C05 持剑/斩击弧光、E01 命中特效。
- 测试：前/后/边界角度、近/远、同次挥砍去重、多个敌人、暂停和重开；近战半径与自动索敌范围分别断言。

## T33 新敌人/地图的逐件扩展

- 输入：`docs/整理设计/角色与敌人/角色与敌人.md` 当前只有方向，没有具体敌人/地图数值。每新增一个对象，先写 ID、行动、攻击、掉落、波次、性能预算和验收卡。
- 操作：新敌人优先复用 `EnemyActor` + `EnemyDefinition`/组件；新地图先明确可通行区域、摄像机边界、屏幕外生成逻辑和背景层，再修改 Arena/RunDefinition。B07/B08 素材清单中的史莱姆/蝙蝠目前未进入新版可玩关卡，可先明确是否恢复，不仅为了消耗素材而添加。
- 测试：生成/追踪/失效目标、掉落、碰撞层、Boss 时段、地图边界、高密度数量上限；新地图不能让敌人在玩家视野内出生。

## T34 现有素材债与界面收口

- 输入：`docs/整理设计/美术素材清单.md` 的“待补充/未接入”：飞叶刃、骨棒、铃铛的逐帧武器动作，角色头像、Boss 徽记、其余 E01 反馈，已制但未用的竖版升级卡。
- 操作：按**一个素材组一轮**补概念/透明帧/图标、`SpriteFrames` 和节点引用；保留旧资源做回退。竖卡接入前先确认横向三选一在 1280×720 的可读性与焦点导航，不能仅换贴图。每批记录提示词/原稿来源/尺寸/alpha/实拍路径。
- 测试：实际游戏窗口逐帧、左右镜像、裁切、锚点、清晰度、UI 中文不烘焙到图中；已有动画专项和 v2 美术专项通过。

## T35 完整游玩、性能与平衡验收

- 输入：已完成的任务记录、`docs/TASKS.md` 中仍未完成的五分钟人工游玩、macOS 稳定性与长期平衡。
- 操作：分别人工完成胜利和失败局；从主菜单选角色/武器，经历拾取、满格、质变、套装、Boss、结算、存档退出重进和连续重开。记录装备/升级使用率、敌人密度、帧率、画面遮挡、音量与手感；只针对有证据的问题做小范围数值调整。
- 测试：现有全部快速 smoke、相应 soak 与高密度测试；GUI 整局截图/记录和 macOS 目标机器启动。胜负/重开/存档/资源引用无阻断性错误。未实现且仍待决策的剑分支、未来地图、成就/装扮等不应被写成通过。
