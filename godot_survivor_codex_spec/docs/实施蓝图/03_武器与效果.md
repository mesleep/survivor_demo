# 03｜弓、法杖与联动

统一约束：武器参数在 `data/weapons`、弹体参数在 `data/projectiles`；运行时状态在控制器/组件。每个任务同时交付相应 C/D/E 编号素材、中文升级文案与专测。已有四把武器继续工作。不要为每个分支复制整个 `WeaponController`；新增攻击形态先封装可测试能力，再由分支配置选择。

## T12 基础弓箭

- 输入：`WeaponDefinition`、`ProjectileDefinition`、`WeaponController.request_fire()`、T04 候选池。先定基础弓的冷却、伤害、射程、箭速/寿命与升级级数。
- 操作：用新 `.tres` 组合弓与直线箭；接入候选池、获取卡、装备栏、基础升级；提供 C03 弓/箭/图标与 D01 箭体，至少有待机与发射可见变化。角色基础范围与武器范围仍取较小值索敌。
- 测试：获得前不能升级；获得后自动锁定最近合法目标、正常发射/命中/死亡清理；与旧武器同持、重开和共享 Resource 均正常。GUI 看持弓姿态与箭矢朝向。

## T13 弓：多重射击

- 输入：T12 与 T05/T06 的互斥分支模型；确定轮间时间、每轮箭数、穿透升级上限。
- 操作：新增“同一次攻击周期内多轮发射”的运行时调度，第二轮使用当时仍有效的目标或约定方向；控制器/玩家离树、结算、重开时取消延迟任务。多重质变和专属“轮次+1”“穿透+1”是两个不同升级 ID。
- 测试：两轮时间间隔、每轮箭数、冷却只计算一次、目标死亡、暂停/结算取消、轮次升级和穿透升级分别生效；不得把弹数 +1 实现成穿透 +1。

## T14 弓：万箭齐发

- 输入：T13 的多轮能力已存在，但本分支只改变**每轮弹数**；先定扩散角与弹数上限。
- 操作：新增互斥的“万箭齐发”质变与专属弹数升级；复用当前散射公式并保证零扩散多弹不会重叠。不得错误地继承多重分支的轮次增加。
- 测试：一次攻击周期的轮数保持设计值，单轮箭数按级别加一，角度对称且实例位置不完全重合；两条弓分支不能在同一局共存。

## T15 基础法杖/蓄力法球

- 输入：当前星光魔杖是既有武器；设计稿中的“法杖”须决定是**新武器**还是既有魔杖升级线，不能静默创建两个同名能力。先定蓄力期间能否移动/换目标、释放时目标消失如何处理。
- 操作：确定 ID 后建立基础法杖数据、可取消的蓄力状态和高伤法球；若复用既有魔杖，保留旧 `.tres` ID 和测试兼容。交付 C04/D01 对应造型与中文卡文案。
- 测试：蓄力/冷却分别计时，重复请求不能叠加蓄力；目标释放、玩家死亡、暂停/结算/重开安全取消；法球实际命中与伤害可断言。

## T16 爆炸与范围命中

- 输入：T15；先定首个碰撞触发、爆炸半径/伤害、同一目标能否同时吃直击与溅射。
- 操作：新增一次性 AoE 命中能力，爆炸使用受控阵营/目标查询及同次爆炸去重；配置爆炸分支与溅射升级。特效 E02 与 D02 爆炸球只做透明可复用素材，不把范围画死在贴图里。
- 测试：中心/边界/范围外、同帧重叠、多个目标、目标释放、Boss、穿透和结算后清理；无重复受伤或节点残留。

## T17 火焰持续伤害与地面火坑

- 输入：T16 的范围能力和 T10 伤害标签；先定 DoT tick、持续时间、叠加/刷新规则与吸血资格。
- 操作：将持续伤害做成可复用状态/区域能力；火舌的持续发射与“喷射后火坑”分开实现，防止一次碰撞每帧无上限扣血。配置火焰分支与专属长度/持续时间升级，交付 E02/D02。
- 测试：固定时间内 tick 数、目标进出范围、多个火坑重叠、来源离树、敌人死亡、暂停与重开；对照规则验证吸血和暴击是否允许。

## T18 威能分支

- 输入：T15；先决定“射速”“攻击间隔”是同一冷却参数，防止重复乘算。
- 操作：仅用数据/运行时修正提高伤害、射程、攻速；质变后专属升级有独立上限。交付威能球 D02 与图标 C04，不增加另一套发射脚本。
- 测试：三项修正前后实测值、下限钳制、与通用 Buff 叠加、晚获取和共享 Resource 不变。

## T19 寒冰减速/冻结/分裂

- 输入：T15 与状态组件；先定减速比例、冻结时长、重复命中刷新或叠加、分裂角度和次数上限。
- 操作：先做冰枪穿透与减速，再做冻结，最后在首击处生成小冰枪；若范围过大，按“减速→冻结→分裂”拆三次提交/测试。速度修正只作用敌人运行时，失效/死亡时清理。交付 C04/D01/E03。
- 测试：穿透命中不同敌人各一次、减速/冻结恢复、Boss 免疫若有、分裂弹不递归分裂、敌人离树与重开无残留状态。

## T20 附魔箭与法杖分支联动

- 输入：T12 及法杖四分支能力；先定 D08 的继承为快照还是实时关联，以及法杖未质变时卡片是否可出。
- 操作：升级候选验证同时持弓与已质变法杖；附魔弓分支使用统一效果映射：爆炸→溅射、火焰→DoT、威能→攻速/射程、寒冰→减速/冻结。各映射复用法杖的通用能力，但数值独立配置；不直接读另一个控制器的私有字段。交付四种附魔箭 D02。
- 测试：无杖/未质变/各四分支的候选资格与效果，互斥弓分支，来源法杖节点失效、重开和画面可读性。
