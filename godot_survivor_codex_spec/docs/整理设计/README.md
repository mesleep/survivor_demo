## 贯穿多份设计的规则

1. 玩家在开局前从武器库选十种武器，作为本局可能获得的武器；局内拟定最多装备六种装备。十种候选、六个装备位和防具占位之间的关系仍待明确。
2. 武器既有基础等级升级，也可在一局内选择一次质变。质变后出现对应的专属升级；部分质变和装备套装有联动效果。
3. 局内 Buff 应与本局选定的武器池对应。角色的通用属性强化和单件装备的强化应分开定义。
4. 局外解锁决定可选角色与武器，主菜单承担这些选择和永久成长的管理入口。

各文档的“待明确”只标出原稿尚未决定的规则，不替原稿补造数值或机制。
