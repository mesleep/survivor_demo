# 角色与敌人

## 角色方向

原稿希望建立可以继续补充角色的设计框架。目前提出的第一位角色是**远程射手**：擅长用远程武器持续输出，使用远程武器时获得额外加成。

角色加成的具体形式、数值、限制和成长方式尚未确定。局外成长系统还提出，未来应增加更多可解锁角色；角色可通过成就或花费金币解锁。部分角色也可以和特定装备或题材产生联动。

## 敌人与地图

原稿中的“敌人设计”文件目前为空。局外成长草案提出，随着角色和武器增加，也需要扩充敌人和地图。敌人的种类、行为、掉落和地图主题均未展开。

## 待明确

- 远程射手的加成具体影响哪些远程武器属性，以及是否有专属技能。
- 后续角色的定位、差异和解锁条件。
- 敌人类型、行动方式、强度变化、奖励和地图设计。
