# 防具方案

防具暂包括盔甲、头盔和手套。它们也有基础升级与质变；科技质变可以组成三件套。具体防御计算和数值尚未确定。

## 盔甲

**基础形态**：增加防御，但降低一部分移动速度。基础升级进一步提高防御，并减轻移速惩罚。

| 质变 | 效果 | 质变后可选升级 |
| --- | --- | --- |
| 反伤刺甲 | 身边形成反伤刺圈，接触的敌人会受伤；角色受伤后还会向敌人返还伤害。 | 扩大刺圈范围；提高返还伤害。 |
| 骑士盔甲 | 大幅减少受到的伤害。 | 受击时有概率完全免伤，概率可升级，但不应高到近乎无敌。 |
| 狂战盔甲 | 每秒失去生命，换取大幅提高的吸血能力。 | 减少每秒失血；半血以下进一步提高吸血；获得一次免疫死亡的能力。 |
| 科技战甲 | 单独装备也能每秒获得经验；与科技头盔、科技手套联动。 | 提高宝石给予的经验；提高每秒获得的经验。 |

## 头盔

**基础形态**：增加的防御少于盔甲，但没有移速惩罚。基础升级继续提高防御。

**科技头盔质变**：单独装备也能每秒获得经验；与科技战甲、科技手套联动。专属升级提高宝石经验和每秒经验。

## 手套

**基础形态**：提供很少的防御，同时缩短攻击间隔并提高射程。基础升级继续提高这些属性。

**科技手套质变**：单独装备也能每秒获得经验；与科技战甲、科技头盔联动。专属升级提高宝石经验和每秒经验。

## 科技三件套

同时拥有科技战甲、科技头盔、科技手套时，角色大幅提高移速，表现为飞行；另获得科技发射器，可向周围随机发射轰炸导弹，也可发射激光炮。原稿将其作为科技套装的核心联动。

## 待明确

- 防御、减伤、反伤、持续失血、吸血和一次免死各自的结算顺序及数值边界。
- 科技三件套要求仅持有三件基础装备，还是必须分别选择科技质变。
- 科技发射器的导弹与激光是同时获得、交替攻击还是后续升级分支。
- 原稿中的“科技盔甲”和“科技战甲”是否统一为同一装备名称。
