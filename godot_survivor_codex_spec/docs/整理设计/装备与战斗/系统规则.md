# 装备与战斗系统规则

## 装备的范围

“武器设计”在原稿中实际指更广义的**装备设计**。装备暂分为武器和防具：武器承担攻击，防具提供防御或其他能力。不同装备之间可以产生联动，成为局内构筑的核心。

## 开局选择与局内获取

- 进入地图前，玩家从武器库中选择十种武器，组成这一局可获得的候选池。
- 原稿拟定角色在局内最多装备六种装备。
- 本局出现的武器应限定在开局选出的十种之内。

原稿对“带入地图”和“本局掉落”的表述并存。这里将十种武器整理为**本局候选池**；是否开局直接持有其中任何武器、武器通过掉落还是升级获得、六个位置是否包括防具，都保留为待定规则。

## 单件装备的成长

1. **基础升级**：每件装备可以有自己的基础强化项，例如伤害、射程、攻击间隔或防御。
2. **质变**：一件武器在同一局中拟定只能选择一种质变。质变可以改变攻击方式或附加功能。
3. **质变专属升级**：选定质变后，才解锁对应的强化选项。
4. **装备联动**：部分质变需要先持有另一件装备，或根据另一件装备已选的质变改变效果；套装也可提供额外能力。

基础升级、质变和质变专属升级都应有清楚的层级及候选条件，避免同一武器的 Buff 无限堆叠。具体等级上限和出现时机尚未确定。

## 联动示例

- 弓箭的“附魔箭矢”需要持有法杖，并继承法杖所选质变的部分效果，详见[武器方案](武器方案.md)。
- 科技战甲、科技头盔和科技手套构成三件套，同时装备可获得移动和额外攻击能力，详见[防具方案](防具方案.md)。

## 题材灵感

原稿列举了下列题材灵感，角色也可以参与联动。这些目前还没有确定的装备规则或制作方案：

- 菜鸟警察的手枪，例如里昂的手枪。
- 六眼及“天上天下、为我独尊”等技能，与咒力核心联动；灵感来自《咒术回战》。
- 可释放忍术的忍术卷轴；灵感来自《火影忍者》。
- 日轮刀；灵感来自《鬼灭之刃》。
- 科技盔甲、科技手套、科技头盔组成的套装；灵感来自钢铁侠。

## 待明确

- 六个装备位是否由武器与防具共用，以及获取新装备时的替换规则。
- 十种候选武器的选择、开局持有、局内获得和掉落规则。
- 基础升级、质变与专属升级各自的等级、出现条件及互斥关系。
- 联动效果在缺少前置装备、装备被替换或另一件装备尚未质变时如何处理。
