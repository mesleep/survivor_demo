# 武器方案

以下是原稿提出的武器示例。数值描述均为相对定位，尚未确定实际数值。每件武器的基础升级、质变与专属升级遵循[装备系统规则](系统规则.md)。

## 弓箭

**基础形态**：一次攻击射出一支箭；射速、威力和射程均为中等。基础升级方向包括提高射速、威力和射程，以及缩短攻击间隔。

| 质变 | 效果 | 质变后可选升级 |
| --- | --- | --- |
| 多重射击 | 每次攻击间隔内射出两轮箭。 | 增加射击轮次；提高穿透能力。原稿预留的第三项尚未写出。 |
| 万箭齐发 | 每轮射出的箭矢数量增加一支。 | 继续增加箭矢数量。 |
| 附魔箭矢 | 仅在持有法杖时可选；箭矢附带法杖当前质变的效果。 | 获得一次与法杖质变相关的升级选项，具体选择规则待定。 |

附魔箭矢与法杖的对应关系：

- **爆炸法术**：命中后爆炸，对周围敌人造成溅射伤害。
- **火焰法术**：命中的敌人受到持续伤害。
- **威能法术**：提高射速和射程，缩短攻击间隔。
- **寒冰法术**：命中后冻结敌人，使其暂时不能行动。

## 法杖

**基础形态**：蓄力后发射法球；射速慢、威力大、射程远。基础升级方向包括提高射速、威力和射程。

| 质变 | 攻击变化 | 质变后可选升级 |
| --- | --- | --- |
| 爆炸法术 | 法球碰到第一个敌人后爆炸，对周围敌人造成较低的溅射伤害。 | 扩大溅射范围；爆炸后留下持续灼烧的火坑，并提升火坑伤害及爆炸半径；提高溅射伤害。 |
| 火焰法术 | 改为持续喷射火舌，对沿途敌人造成持续伤害。 | 延长喷射时间；提高火舌距离或射程；喷射后留下燃烧小径，并提高其持续时间与伤害。 |
| 威能法术 | 大幅提高基础伤害、射速与射程，缩短攻击间隔。 | 继续强化上述属性，具体档位待定。 |
| 寒冰法术 | 发射可穿透敌人的冰枪，沿途造成伤害和减速。 | 增加冰枪数量；使冰枪命中首个敌人后分裂成小冰枪，沿途继续造成伤害和减速，并可升级小冰枪数量。 |

## 剑

剑是近战武器占位方案。基础攻击朝有敌人的一侧作扇形斩击；基础升级、质变和质变专属升级尚未设计。
