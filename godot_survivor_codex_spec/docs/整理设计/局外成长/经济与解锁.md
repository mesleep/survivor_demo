# 局外成长、经济与解锁

## 目标与入口

原稿希望对局之外也有持续成长和内容解锁。进入游戏后先到主菜单，在那里管理永久强化、角色、武器与装扮，并在开局前选择本局武器候选池。

## 金币来源

1. 对局中敌人死亡时，有概率额外掉落金币。
2. 对局结束后，根据击败的敌人数量发放金币。
3. 完成局外任务或成就获得金币。

## 金币用途

### 全角色共享的永久强化

永久强化不依赖特定角色，应以共通基础属性为主，幅度有所克制。原稿举出的方向有：移速、基础伤害、每秒生命恢复、吸血、防御，以及刷新局内 Buff 选项的次数。每项可以分级购买，价格随等级提高。

### 内容解锁

- **角色**：通过达成成就或花费金币解锁。
- **武器**：逐步解锁更多可加入武器库的武器。
- **装扮**：解锁角色和武器的不同外观。

## 开局配置与内容扩展

玩家拟定在进入地图前从武器库选十种武器，本局只出现这十种武器；局内最多装备六种装备。装备位、候选池与实际获得方式的关系见[装备系统规则](../装备与战斗/系统规则.md)。

为支撑长期游玩，原稿还提出增加更多角色、武器、敌人和地图。武器成长应有质变与专属升级，而非无限叠加普通 Buff。

## 待明确

- 金币掉落概率、结算公式、任务与成就列表，以及奖励额度。
- 永久强化的具体数值、等级上限、价格曲线和重置规则。
- 角色、武器和装扮各自的解锁条件及购买方式。
- 主菜单需要提供的具体页面和开局配置流程。
