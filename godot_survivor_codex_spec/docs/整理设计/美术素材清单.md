## 统一交付规则

- **概念图**：用于确定角色轮廓、服装、武器结构、材质、配色和效果形态；可带说明，但不得直接作为游戏精灵切图。
- **游戏素材**：角色、装备、弹体和特效使用真正透明背景的 PNG；同一对象各帧保持相同视角、比例、重心和脚底基线。界面素材不烘焙文字，游戏中的中文由 Godot 绘制。
- **视角与可读性**：角色和敌人采用俯视三分之四朝右视角，向左时可镜像。角色在 1280×720 游戏画面中仍需容易辨认；特效不能遮住敌人、掉落物和生命信息。
- **尺寸参考**：现有游戏窗口为 1280×720，场地为 2560×1440。建议角色原始单帧 256×256、Boss 384×384、武器与弹体 128×128、物品和状态图标 128×128；最终像素尺寸以同一批素材能在游戏里保持一致为准。地图游戏图以 2560×1440 的 16:9 画布交付。
- **原创建议**：动漫、电影和游戏联动灵感只保留玩法意象与类别，不复刻人物面容、服装、标志、专有纹样或知名道具造型。

交付时按编号逐项出图，建议把概念图与游戏素材分别存放。文件名保留编号和对象名，例如 B01_小法师_设定.png、B01_小法师_待机.png、B01_小法师_行走_01.png。旧图不覆盖，新图统一放在独立版本目录；每批附上对应清单编号，方便后续接入与核对。

## 制作顺序

1. 先确认 A 类三张基准图，再制作 B01、B03～B09、C01～C02、D01 中现有弹体、D03 的经验宝石、E01、F01 与 F04。现有四宠素材一并重画，避免游戏后半程或后续扩展混用两种画风。
2. 随后制作新射手和主菜单视觉。主菜单功能尚未开发，先保留无字可复用组件。
3. 完成弓箭、法杖、剑、防具及其质变的概念图，再按已确定的玩法生产对应游戏素材。
4. 未来角色、敌人、地图、装扮与原创化灵感包保留规划位，等数量和机制明确后再定实际制作量。

制作验收以单项可独立裁切、透明背景真实有效、帧间角色不跳位、缩小到游戏显示尺寸仍清楚为准。文字、数值与 Buff 描述由游戏界面绘制，不写在图片中。
