# 局内升级与 Buff

## 获取方式

角色在一局游戏中升级后，从候选 Buff 中选择强化。原稿把 Buff 分为通用基础属性和装备专属强化两类；装备质变及质变后的专属升级也应纳入局内成长规则。

## 通用基础属性 Buff

原稿提出的强化方向包括：移动速度、经验宝石拾取范围、吸血、暴击率、基础防御，以及全部武器的射程。这些是面向角色或当前装备组合的通用属性，不绑定某一件武器。

射程需要分清不同层次：每一种武器应有自己的射程范围；“全部武器射程”Buff 再影响角色持有的武器。还需明确索敌范围、攻击判定和子弹实际飞行距离之间的关系。

## 装备专属 Buff

每件武器应有对应的升级项，并设定等级。原稿希望局内能出现的武器及其专属强化围绕开局选定的十种候选武器展开。具体武器的基础升级和质变后升级见[武器方案](../装备与战斗/武器方案.md)，防具见[防具方案](../装备与战斗/防具方案.md)。

质变拟定为单件武器在一局中只能选择一种；选择后才解锁该质变的专属升级。武器与装备联动也可能改变可选项，例如弓箭在持有法杖后才可选附魔箭矢。

## 待明确

- 通用 Buff、单件装备基础升级、质变与质变专属升级如何共同进入升级候选池。
- 各强化的等级上限、增长方式、出现权重与互斥条件。
- 开局十种候选武器中尚未获得的武器，其专属 Buff 是否可以提前出现。
- 射程强化作用于角色范围、单件武器范围还是弹体可达距离。
