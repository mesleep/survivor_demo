# 数据与素材索引

本文是「改数值、换素材」的总入口：按系统列出数据文件位置、关键字段与对应素材目录，并说明三种修改方式。游戏内的可视化入口见「数值 / 素材工作台」。

## 一、三种修改方式

1. **游戏内工作台（推荐，直观）**
   - 主菜单 → 设置 → 「数值/素材工作台」。
   - 左侧按系统分类展开资源；右侧按中文字段编辑数值、预览与更换素材。
   - 改动即时生效（当次运行），点「保存到文件」写入对应 `.tres`；「放弃修改并重载」恢复文件内容。
2. **Godot 编辑器 Inspector（适合批量）**
   - 用 Godot 打开项目，在 FileSystem 里按下面的路径打开 `.tres`，Inspector 已按中文分组。
3. **直接替换同名 PNG（最快换画风）**
   - 保持文件名不变替换 `assets/` 下的 PNG，重新运行即生效（Godot 自动重导入）。

> 约定：共享 `.tres` 只读；运行时状态（等级、金币、当前选择）不会写回资源。保存工作台修改会直接改项目文件，建议改前先提交 Git。

## 四、常见操作

- **改一个升级卡的数值/图标**：工作台 → 升级卡 → 选卡 → 改 `value` 或「更换素材」→ 保存。
- **改武器手感**：工作台 → 武器 → 选武器 → 调「开火参数」。
- **改敌人强度**：工作台 → 敌人 → 选敌人；或改「波次与难度」里的倍率。
- **改单局时长/Boss**：工作台 → 波次与难度 → `default_run.tres`。
- **换界面按钮/面板图**：工作台 → 界面样式与贴图 → 打开对应 `StyleBoxTexture` → 更换 `texture`，再调九宫格边距。
- **增删可选内容**：工作台 → 内容目录 → `default_catalog.tres`，增删数组元素（用 Godot Inspector 拖拽更顺手）。
- **重置进度**：主菜单 → 设置 → 「重置存档」（清空金币、解锁与永久强化）。

## 五、注意事项

- 工作台直接写 `res://` 下的 `.tres`，只适合开发环境；正式导出包内资源只读。
- `SpriteFrames` 这类复杂资源不由工作台直接编辑，请在武器/弹体/敌人的 `visual_frames` 字段里更换引用；序列帧 `.tres` 由 `tools/build_v2_visual_resources.py` 等脚本或 Godot 编辑器维护。
- 字段中文说明来自脚本里 `@export` 上方的 `##` 注释；新增字段时按同样格式补注释，工作台会自动显示。
